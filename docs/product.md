# ToDoList 本地 V1 产品与交互说明

ToDoList 把当天最重要的任务放在 Mac 桌面右侧，让你随时了解计划与进度。桌面卡片运行于 Übersicht，完整编辑器运行于本机浏览器。服务、持久化与编辑器均独立于 TaskMap 和 Project Explorer。没有账号、云端写入或多设备同步。

## 桌面卡片

默认尺寸为 364 像素宽，位于右上方（距顶部 76、右侧 28 像素），显示最多 6 个任务。卡片使用 macOS 系统字体、圆角和半透明背景，自动跟随 macOS 浅色或深色外观；透明层后有足够实色以保持复杂壁纸上的文字对比度。它是 Übersicht 桌面层中的内容，普通窗口可以遮挡它。

顶部显示服务所配置时区中的日期、星期、完成任务数、计划总时长和已完成任务的预计总时长。完成进度按任务数量计算（已完成数 ÷ 非取消数），不按耗时加权。取消任务不计入分母和计划时长；底部保留取消数量提示。实际用时仅在编辑器中填写，不替代卡片的预计时长。

任务行依次显示完成勾选框、标题、描述、预计分钟数、类别和优先级；进行中任务有额外提示。标题与描述过长时省略，点击任务在浏览器中打开完整详情。任务按当天 `order` 排列，ID 用作 React key，不使用数组位置作为身份。

超过显示数量时显示“还有 N 项”按钮，打开完整编辑器。屏幕较矮或用户缩放较大时，任务区在卡片内部滚动，外框高度随屏幕限制。顶部统计与底部操作仍保留。建议配置缩放、顶部偏移和显示数量以适配自己的屏幕。若人为配置的顶部位置超出屏幕，需在配置文件中修正。

每 30 秒从本地服务读取一次，不进行每秒轮询。卡片自身勾选成功后立即读取最新数据；浏览器中的修改最迟在下一轮读取时显示，也可以点击右上角刷新。跨日以服务返回的 `today` 为准，在下一次刷新切换当天任务。服务不可用时保留本次 Übersicht 会话中最后成功读取的数据，明确显示“离线缓存”，并禁用完成勾选。若缓存属于前一天，会标注缓存日期。重启 Übersicht 后不会从内存恢复旧缓存，服务恢复后自动重新读取。

## 点击与系统权限

Übersicht 的桌面交互由它自身的 Interaction 设置控制。先在 Übersicht Preferences 中设置交互快捷键；需要时，在 macOS“系统设置 → 隐私与安全性 → 辅助功能”允许 Übersicht。按住设置的交互快捷键再点击卡片。操作说明保留在文档中，不在卡片底部常驻显示。

没有设置快捷键或没有相应权限时，可以直接访问 `http://127.0.0.1:43117` 编辑计划。端口以安装时配置为准。卡片的读取使用 Übersicht 官方 `run()` 命令接口调用系统 curl；任务文本经过 shell 参数引用，不拼接为可执行代码。不会绕过 macOS 权限机制。

在 Übersicht 中把卡片设置为主屏幕显示。虚拟桌面与全屏应用中的显示行为遵循 Übersicht 和 macOS 的桌面设置；本工具不强制改变系统的 Spaces 配置，也不增加置顶窗口。登录时启动属于用户可选配置。

## 位置、宽度与外观

安装后的 Widget 目录中有以下文件：

- `daily-planner.jsx`：桌面卡片入口。
- `src/config.js`：用户配置。可调整 `top`、`right`、`width`、`scale`、`maxTasks`、`theme` 和刷新周期。
- `src/connection.js`：安装脚本生成的本地服务端口。重新配置端口时运行安装脚本更新连接设置。

修改配置后在 Übersicht 菜单中刷新 Widget。`theme` 可为 `auto`、`light` 或 `dark`。显示数量限制为 1—7 项，刷新间隔限制为 15—300 秒，缩放限制为 0.6—1.6 倍。默认设置避免遮挡大面积桌面，卡片以外的区域不接管 Finder 交互。

## 完整编辑器

桌面卡片同样支持“今日计划 / 七日计划”直接切换。七日日期栏显示每日数量与分钟数，选择日期后可查看和勾选该日真实任务，箭头翻阅前后七天。切换视图只改变显示，不写入任务；任务列表在卡片内滚动。

今日视图适合执行当前计划；七日视图用于观察未来一周的负荷。每天显示预计总时长。点击任务卡片的标题、描述、标签、时长或空白处，均可打开该任务的只读详情；点击详情中的“编辑”后才显示表单，列表中的编辑图标也可直接进入表单。勾选、排序和删除按钮各自执行原操作。详细说明随内容、输入和窗口宽度自动展开，超长表单在整个弹窗内滚动。鼠标关闭详情后不在任务名称上保留焦点框；键盘操作保留焦点提示。选中文字仍可复制；键盘可聚焦任务标题并按 Enter 或空格打开详情。表单支持标题、描述、日期、预计分钟数、实际分钟数、类别、优先级和状态。排序按钮改变同一天的顺序；日期修改与移动操作可以调整安排。删除后提供撤销入口。

同一个本地任务接口服务于卡片与编辑器，每次写入携带当前版本。若另一个页面或卡片已修改数据，旧版本写入被拒绝；用户看到提示后重新确认，不会静默覆盖。导入与批量操作使用“预览 → 确认执行 → 撤销”。撤销也需要版本一致，若之后已有其他修改，必须先处理最新状态。

打开已有任务时，默认显示名称、完整说明和任务信息，不显示输入框。点击“编辑”才进入表单，名称不会自动获得输入焦点；取消或按 Escape 放弃本次输入并返回查看，保存成功后显示更新后的详情。新增任务直接显示表单并聚焦空名称。桌面跳转与网页内点击使用相同的默认查看入口。单行日期、文本、数字及下拉控件统一为 44 像素高，成对字段等宽、对齐，日期内容在框内居中。

## 首次导入示例计划

`examples/week-plan.json` 是 **2026-10-23 至 2026-10-29 的演示计划**，共有 37 项任务。所有任务都是待做，实际用时为空；它不表示已经开展或完成的真实工作，程序不会自动导入。包含 AI 应用岗位筛选与投递、信息安全 Agent 项目理解、Python Coding、408、日终复盘，并在周末留出休息。

在编辑器中选择 JSON 文件，先预览日期、数量与每日总时长，再确认导入。默认选择“追加”，保护已有计划。日期已经过去时，先修改 JSON 中的 `date`（保留稳定 ID），或导入后在编辑器移动到所需日期。示例按 Asia/Shanghai 编排。

导入策略的含义：

| 策略 | 行为 | 使用场景 |
| --- | --- | --- |
| 追加（默认） | 增加新任务；已有 ID 冲突会被拒绝 | 第一次导入、增加新计划 |
| 合并 | 以稳定 ID 匹配已有任务并更新，新增未匹配任务 | 导入同一份计划的修订版 |
| 覆盖所含日期 | 仅替换导入文件涉及日期的任务 | 明确重新规划某几天 |

整个文件先校验再提交。非法日期、字段、时长和重复 ID 会阻止导入；失败时保留原有计划。导出 JSON 可作为人工备份和后续自然语言编辑的数据输入。

## V1 边界与验收原则

V1 不提供远程 ChatGPT 接入，不把本机服务暴露给互联网。未来 AI 批量调整需要额外的身份与调用授权，再通过相同预览、版本检查、事务和撤销能力接入。示例、预览与真实存储须始终区分。

自动化测试不能证明 macOS 已授予辅助功能、登录后自动启动或真实桌面点击成功。测试报告必须区分程序测试与实际 GUI 操作，并明确列出未完成的机器重启、重新登录和系统权限检查。卡片显示正确、数据服务重启后任务保留，以及 Übersicht 重启后重新读取同一数据，均需要分别验证。
