## 尚未验证与已知限制

- **原生桌面上的交互快捷键和辅助功能授权未实测通过。** 原生应用自动化只读到了背景窗口，无法可靠定位前景桌面卡片；已在实际 Übersicht JSX 渲染页验证按钮和原生命令桥。需用户在 Preferences 设置快捷键并在 macOS 授权后于桌面确认。
- **未执行 Mac 注销/登录或重启。** 已实测 LaunchAgent 加载、监督重启和数据持久化；下一次真实登录与 Übersicht 自身登录启动仍需用户验收。
- **未完整验收多显示器、全部 Space、Stage Manager、全屏遮挡、Finder 拖放与浅/深壁纸组合。** 主屏选择和桌面层行为由 Übersicht 控制。位置/主题/尺寸均可配置。
- **未做长时电池/内存泄漏压力测试。** 0.0% CPU 与70MiB RSS只是一次空闲快照；实现无每秒轮询，Widget默认30秒，编辑器可见时60秒兜底，SSE无周期性计算。
- 编辑器到桌面外部写入的显示延迟最多约30秒；卡片自身勾选和手动刷新立即读取。
- 恢复为较低 revision 的新数据库后需 Refresh All Widgets / 刷新浏览器，清除旧会话缓存。
- launchd 日志需要长期使用者定期检查/清理；手动启动日志自动保留一个 previous。
- V1未部署远程MCP、模型、账户、同步或局域网接口；未来边界见架构文档。

## 用户最后的验收步骤

1. 在 Übersicht 菜单选择 ToDoList 卡片（`daily-planner`）显示在主屏，Refresh All Widgets；配置交互快捷键并自行授权辅助功能，桌面直接勾选一次。
2. 导入 examples/week-plan.json 前先预览，按自己的实际日期与时长调整。
3. 新增自己的持久化测试任务，关闭浏览器，确认桌面保留；stop/start及 Übersicht 退出重开后核对。
4. 如果需要登录启动，运行 `./planner login enable` 并打开 Übersicht 的 Launch at Login；保存其他工作后自行注销再登录，核对卡片和任务。
